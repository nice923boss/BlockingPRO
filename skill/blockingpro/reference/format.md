# 專案格式 project.blockingpro.json

BlockingPRO 專案是一個 JSON 檔。編輯器、render.html、tools/check_scene.py 用同一份 runtime/schema.js 補預設值和檢查，所以這裡寫的規則三邊一致。代號清單（動作、物品、體型、燈光預設）見 catalog.md，自訂物品見 assets.md。

## 1. 座標與方向

- 單位公尺、秒、角度（度）。Y 朝上，地面是 y = 0。
- 俯視時 X 往右、Z 往鏡頭（畫面下方）。場景通常圍繞原點 (0, 0, 0) 擺。
- `yaw`（水平朝向）：0 面向 +Z，90 面向 +X，180 面向 -Z，-90（或 270）面向 -X。公式：yaw = atan2(dx, dz)。
- yaw 0 的角色，自己的左手邊是 +X，右手邊是 -X。關節名稱的 l / r 是角色自己的左右。
- 兩人面對面：A 站 (0, 0, -0.6) yaw 0，B 站 (0, 0, 0.6) yaw 180。
- 角色與物品的位置是腳底（底面中心）；攝影機與燈光的位置是鏡頭或燈本身。

## 2. 路徑 path 與關鍵影格

角色、物品、燈光、攝影機都用同一種路徑：

```json
"path": { "curve": "smooth", "keys": [ { "t": 0, "v": [0, 0, -4], "e": "inOut" }, { "t": 3, "v": [0, 0, 0] } ] }
```

| 欄位 | 說明 |
|---|---|
| curve | `smooth`（預設，平滑曲線穿過每個點）或 `linear`（折線）。急轉彎、沿牆走用 linear。 |
| keys[].t | 秒。會自動排序。 |
| keys[].v | 位置 [x, y, z]。角色、物品 y 通常是 0。 |
| keys[].e | 從這一格到下一格的緩動：linear（預設）、in、out、inOut、hold（停在這格直到下一格才跳過去）。也可以寫自訂速度曲線 `[x1, y1, x2, y2]`（同 CSS cubic-bezier，例如 `[0.7, 0, 0.3, 1]`）。 |
| keys[].yaw | 選填，角色站著不動時的朝向（facing fixed 時也照它轉）。走到定點後要轉身面對別人，就在最後一格寫 yaw。 |

- 第一格之前停在第一格，最後一格之後停在最後一格。只有一格就是固定不動。
- 速度 = 兩格距離 ÷ 時間差。人走路 1.2 到 1.5 公尺/秒，跑步 3 以上；超過人能做到的速度畫面會像滑行。
- 要「停一下再走」：同一個位置放兩格，例如 t 2 和 t 3 都是 [1, 0, 0]。
- 路徑最後一格不要超過 settings.duration（會有警告）。
- 簡寫：固定不動的東西可以只寫 `"pos": [x, y, z]`，等同一格路徑。

## 3. 最上層

```json
{
  "format": "blockingpro",
  "version": 2,
  "name": "場景名稱",
  "settings": { ... },
  "actors": [], "props": [], "lights": [], "cameras": [], "cuts": [], "assets": []
}
```

- `format` 必須是 "blockingpro"。
- `version` 目前是 2。舊版檔案（沒寫 version 視為 1）在編輯器開啟、check_scene 檢查時都會先自動升級，檔案本身不改，編輯器儲存後才是新格式；比目前新的版本會提醒「較新版 BlockingPRO 存的」。
- actors、props、lights、cameras 的 `id` 全部不能重複（跨類別也不行）。id 用英文小寫，例如 hero、cup1、camA。
- settings 欄位見 catalog.md 的「場景設定」。`settings.target` 填要交給哪個 AI 影片模型（預設 `"seedance-2.0"`，可用 `seedance-2.5`、`kling-3.0-omni`、`kling-motion`、`veo-3.1`、`runway-aleph`），長度與解析度上限見 catalog.md 的「目標模型」表。Seedance 2.0 參考影片用 1280x720（直式 720x1280）、總長 15 秒內。

## 4. 角色 actors

```json
{
  "id": "mei", "name": "小美", "kind": "human", "preset": "woman",
  "color": "#e07a5f", "display": "white", "scale": 1,
  "facing": "path", "yaw": 0, "autoGait": true,
  "path": { "keys": [ { "t": 0, "v": [-3, 0, 0] }, { "t": 3, "v": [0, 0, 0], "yaw": 180 } ] },
  "actions": [ { "type": "bow", "start": 3.2, "dur": 2 } ],
  "upper": [ { "type": "wave", "start": 0.5, "dur": 2 } ]
}
```

| 欄位 | 預設 | 說明 |
|---|---|---|
| kind | human | `human` 人、`animal` 動物 |
| preset | man / dog | 體型或動物種類，見 catalog.md |
| name | 體型名稱 | 顯示名稱 |
| color | null | 白模顏色 #rrggbb，null 用預設灰白。多角色時給不同顏色，畫面才分得出誰是誰 |
| display | white | `white` 白模、`joints` 關節節點、`both` 兩者。settings.display 可以整場覆寫 |
| scale | 1 | 整體縮放 |
| body | 無 | 只有人類有。在體型上調身形：`height` 身高（公尺，0.8 到 2.3，取代體型的預設身高）、`build` 胖瘦（0.6 到 1.6，1 是體型原樣，肩寬、臀寬只跟著變一半）、`head` 頭的大小（0.7 到 1.5，總身高不變）。可只寫其中幾項，例如 `{ "height": 1.9, "build": 0.8 }`。`height` 和 `scale` 都是整個人等比放大縮小，差別只在 height 直接寫公尺；兩個都寫時 scale 再乘上去。動作的伸手、雙人動作的站位都照新身形算 |
| facing | path | `path`：移動時面向前進方向；站著時用該格的 yaw，沒寫就沿用前一段（或還沒出發時，下一段）的前進方向。`fixed`：朝 `yaw`，路徑格有寫 yaw 就照格子轉（原地轉身用這個） |
| yaw | 0 | facing fixed 的朝向；path 模式只在整條路徑都沒移動、格子也沒寫 yaw 時才用到 |
| autoGait | true | 依路徑速度自動在待機、走路、跑步之間切換，不用自己放 walk 片段。只有人類：步幅與步頻隨速度變化（慢走步子小而快，加速時步子漸大，走跑之間不換拍），轉彎時身體往彎內傾、頭先轉向彎的方向，原地轉身（`facing: "fixed"` 改 `yaw`）會踏小步轉過去 |
| gait | 無 | 只有人類有。步態風格 `{ "style": "tired", "amp": 1.2 }`，套用到待機、走路、跑步（含 autoGait）。`style`：`normal` 一般、`tired` 疲累（步子短、手垂、駝背低頭）、`hurried` 急促（前傾、彎肘快擺）、`relaxed` 悠閒（挺胸、擺臂與扭腰大）；`amp` 動作幅度 0.5 到 1.5（步幅、擺臂、扭腰一起放大縮小）。可只寫一項。路徑速度要配合風格：疲累 0.7 到 1、悠閒 0.8 到 1.1、急促 1.6 到 2 公尺/秒 |
| actions | [] | 全身動作片段（坐、跳、鞠躬、跌倒、跳舞等） |
| upper | [] | 上半身動作片段，只有人類有，會疊在走路或全身動作上（揮手、講電話、喝東西） |
| hands | 無 | 只有人類有。平常的手勢 `{ "l": "open", "r": "fist" }`，可只寫一邊，見下方「手勢 hands」 |
| gaze | [] | 視線片段：一段時間內脖子和頭轉向另一個角色或固定點，見下方「視線 gaze」。人和動物都可以用 |

### 動作片段 clip

```json
{ "type": "sit", "start": 2, "dur": 1.5, "params": { "seat": 0.47 }, "hold": true, "blend": 0.3 }
```

| 欄位 | 說明 |
|---|---|
| type | 動作代號，見 catalog.md。人和動物的清單不同 |
| start / dur | 開始秒數、長度（秒） |
| params | 選填，動作參數（範圍見 catalog.md） |
| hold | 選填。true：片段結束後停在最後姿勢；false：淡回走路或待機。省略時用 catalog.md 的「結束後」預設 |
| blend | 選填，和前一個狀態交叉淡入的秒數，預設 0.3。長故事的下一段在 t = 0 延續前一段結尾的片段（例如坐著）時寫 0 |
| hands | 選填，只有人類。這個片段顯示時的手勢，蓋過動作本身的手勢，見下方「手勢 hands」 |

- 同一軌的片段依 start 排序，後一個開始時接手前一個。
- 走路或跑步交給 autoGait 就好（路徑在動，腳就會動）。手動放 walk 片段只在想強制原地踏步或改步幅時用。
- 想讓同一個人走到一半換風格（例如跑完變疲累），放一段 walk 或 run 片段並在 `params` 寫 `style`、`amp`，片段的值蓋過角色的 `gait`。
- 坐下的標準組合：`sit`（1.5 秒）接 `sitting`，起身用 `standUp`。人的位置在椅子中心往椅子正面方向約 0.4 公尺、yaw 和椅子一樣；座高椅子、長椅 0.45，沙發 0.42（`params.seat`）。
- 坐著的人不要移動路徑；要走過去坐下，路徑最後一格停在椅子前，再放 sit。

### 姿勢片段 pose（手動擺姿勢）

編輯器的「擺姿勢」會寫出這種片段，也可以直接寫：

```json
{ "type": "pose", "start": 4, "dur": 2, "hold": true,
  "pose": { "rot": { "rUpperArm": [-80, 0, -10], "rForeArm": [-20, 0, 0], "head": [-10, 0, 0] }, "hips": [0, 0, 0] } }
```

- `rot`：關節名稱 → [x, y, z] 角度。只寫要動的關節，其他維持站姿。
- 轉動方向：手腳 +X 往後擺、-X 往前擺（手臂往前舉是 rUpperArm 負 X）；脊椎、頭 +X 往前彎（低頭）；左臂 +Z 往側邊舉，右臂 -Z 往側邊舉；膝蓋彎曲是 shin +X。
- `hips`：骨盆位移，單位是身高的比例（[0, -0.2, 0] 約蹲低兩成身高）。
- 放在 upper 軌只會套用上半身關節；放在 actions 軌套用全身。
- 姿勢片段預設不會停住，要停在姿勢上加 `"hold": true`。
- 同一時間有上半身片段（例如 holdChild、openDoor）時，上半身片段會蓋過姿勢片段的手臂。

#### 姿勢庫 library/poses.json

編輯器擺姿勢時可以「存進姿勢庫」，所有專案共用，存在 BlockingPRO 資料夾的 `library/poses.json`：

```json
{ "format": "blockingpro-poses", "version": 1,
  "poses": [ { "id": "pose1", "name": "指向遠方", "rig": "human",
               "pose": { "rot": { "rUpperArm": [-80, 0, -10] }, "hips": [0, 0, 0] } } ] }
```

- `pose` 和姿勢片段的 `pose` 完全相同，可以直接抄進片段。
- `rig`：`human`（所有人物體型共用）或動物代號（`dog`、`bird`…）。編輯器只列出同一種骨架的姿勢。
- 同名、同骨架的姿勢會被覆蓋。要帶到別台電腦就複製這個檔案。

### 手勢 hands

```json
{ "type": "point", "start": 2, "dur": 2, "hands": { "r": "thumbsUp" } }
```

- 手勢：`relaxed` 自然、`open` 張開、`fist` 握拳、`point` 食指指向、`thumbsUp` 比讚。寫錯名稱會列為錯誤。
- 左右手各自決定，後面的蓋過前面的：角色的 `hands` → 全身動作的預設手勢 → 上半身動作的預設手勢 → 手上拿著物品（物品的握法手勢） → 全身片段的 `hands` → 上半身片段的 `hands`。都沒有就是自然。
- 動作的預設手勢：point 右手食指指向；wave 右手張開；clap、talk、handsUp、shrug、push、carry 雙手張開；punch、cheer 雙手握拳；phone、drink、think、openDoor、lookPhone 右手握拳；ride 雙手握拳；liftBox、putDown、holdChild 雙手張開。其他動作維持自然。
- 片段淡入到一半時換成它的手勢，淡出到一半時換回來（`hold` 的片段會一直保持）。手勢是直接切換，沒有手指彎曲的過程。
- 物品附著在 `rHand`、`lHand`（或可手持物品沒寫 joint，預設右手）時，那隻手自動換成物品的握法手勢：多數握拳，箱子 `box`、嬰兒 `baby` 是張開手（手掌貼著箱子側面、托著嬰兒）。
- 想要「舉手比讚」「拿著杯子另一手張開」這類組合，在片段或角色寫 `hands` 就好，不必另做姿勢片段。

### 視線 gaze

```json
"gaze": [
  { "start": 1, "dur": 2, "actor": "jie" },
  { "start": 3.5, "dur": 1.5, "point": [2, 1.6, -3] }
]
```

| 欄位 | 說明 |
|---|---|
| start / dur | 開始秒數、長度（秒，至少 0.1） |
| actor | 看哪個角色（角色 id），視線對準對方頭部中央，對方移動時會跟著轉 |
| point | 看固定點 [x, y, z]（世界座標）。actor 和 point 二選一；看物品就寫物品位置加高度 |
| blend | 選填，轉過去和轉回來各花幾秒，預設 0.4 |

- 從 start 開始花 blend 秒轉過去，維持到 start + dur，再花 blend 秒轉回動作本身的頭部方向。
- 只轉脖子和頭（脖子四成、頭六成），身體不轉。可轉範圍：左右 75 度、往上 35 度、往下 45 度，超過就停在極限。對象在身後時要讓角色轉身（facing fixed 加 yaw，或路徑格寫 yaw）。
- 片段依 start 排序；兩段重疊時後一段接手，接連的兩段會從前一個對象直接轉向下一個，中間不會先轉回正面。
- 視線期間蓋過動作本身的頭部動作（點頭、搖頭會被壓掉），想要點頭就讓視線在那之前結束。
- 不能看自己；角色被刪除時，看它的視線片段一起刪掉。

## 5. 物品 props

```json
{ "id": "cup1", "type": "cup", "name": "咖啡杯", "color": "#ffffff", "scale": 1, "facing": "fixed", "yaw": 0,
  "path": { "keys": [ { "t": 0, "v": [0.3, 0.75, 0] } ] },
  "attach": { "actor": "mei", "joint": "rHand", "from": 2.5, "to": 6 } }
```

| 欄位 | 預設 | 說明 |
|---|---|---|
| type | 必填 | 內建物品代號（catalog.md）或自訂物品的 id（assets） |
| color | null | 覆寫主色 |
| scale | 1 | 數字等比縮放，或 [x, y, z] |
| facing | fixed（交通工具是 path） | path 時沿路徑轉向，車子開動就用這個 |
| yaw | 0 | 朝向；物品正面朝 +Z |
| path | | 位置與移動。放在桌上就把 y 設成桌面高（桌子 0.75） |
| attach | 無 | 拿在手上或跟著角色走 |
| state | 無 | 門、電風扇、電梯的開關或轉速，見下方「物品動畫」 |

### 可行走的物品

樓梯 `stairs`、台階 `steps`、斜坡 `ramp`、舞台 `stage`、電梯 `elevator`（catalog.md 標「可行走」）。角色路徑經過它們上方時：

- 路徑的 y 維持 0，身體自動升到表面高度；人的腳用 IK 踩在階面上，動物只有身體跟著升降。路徑 y 比表面高時（例如跳起）以路徑為準。
- 方向：樓梯、台階的第一階在 +Z 側，往 -Z 爬升；斜坡低端在 +Z。用 yaw 轉向；scale 可各軸縮放，高度跟著 y 縮放。
- 尺寸：樓梯 9 階共高 1.4、深 2.52；台階 4 階共高 0.6、深 1.2，剛好接舞台；斜坡高 0.5、長 3；舞台 4 x 0.6 x 3。
- 上舞台：台階放在舞台正面外側，台階中心到舞台中心 = 舞台深 ÷ 2 + 0.6。例如舞台在 [0, 0, -3]，台階放 [0, 0, -0.9]。
- 樓梯沒有頂端平台：樓梯頂端接一個舞台當平台，`"scale": [0.3, 2.3333, 0.4]`（1.2 x 1.4 x 1.2 公尺），中心放在樓梯中心往 -Z 1.86。斜坡頂端同理用 `[0.3, 0.8333, 0.5]`（高 0.5），中心在斜坡中心往 -Z 2.25。
- 從邊緣直接跨上或掉下 0.3 公尺以上時，角色會在一格內跳上去，檢查會出現「直接跨上」或「直接掉下」提醒，改走台階、樓梯或斜坡。
- 自訂物品和其他內建物品（桌子、床）不能走上去；拿在手上（attach）的可行走物品也不算。可行走的物品不列入編輯器的碰撞提醒。

### 物品動畫

- 汽車、機車、腳踏車的車輪依移動的距離滾動（自己的 path，或被騎時騎乘者的 path）；腳踏車被騎（attach 的 joint 是 root）時，曲柄和踏板跟著騎乘者的腳轉，沒人騎時曲柄不動。這些不用另外寫欄位。
- 門 `door`、電風扇 `fan`、電梯 `elevator` 用 `state` 控制：寫一個數字（整段固定），或寫關鍵影格 `[{ "t": 秒, "v": 0 到 1, "e": 緩動 }]`，兩格之間漸變、緩動寫在前一格，超出 0 到 1 的部分以 0 或 1 計。其他類型寫 state 會出現警告並忽略。

| 物品 | state 0 | state 1 |
|---|---|---|
| door | 關 | 往 -Z 開 90 度（門軸在 -X 側） |
| fan | 停 | 全速，每秒 1.5 圈；轉速漸變時葉片跟著加速、減速 |
| elevator | 門關 | 雙開門往兩側滑到全開 |

```json
{ "id": "door1", "type": "door", "path": { "keys": [ { "t": 0, "v": [0, 0, 0] } ] },
  "state": [ { "t": 1, "v": 0, "e": "inOut" }, { "t": 2, "v": 1 }, { "t": 5, "v": 1, "e": "inOut" }, { "t": 6, "v": 0 } ] }
```

- 電梯是可行走的物品：車廂 2 x 1.6 x 2.4 公尺，門寬 1、門高 2.1，門在 +Z 側，車廂地板高 0.05。電梯的 path 往上移時（例如 y 從 0 到 3），站在車廂裡的人跟著升高，人的 path y 維持 0 即可。門要先關再升：state 降到 0 的時間早於 path 開始往上的時間。電梯沒有井道和樓層，出電梯時人要走到同樣高度的可行走物品（例如舞台）上，否則離開車廂就回到地面。
- 編輯器裡選取門、電風扇或電梯，屬性面板的「動畫」區可以逐格改時間與數值，或按「從目前時間開啟／關閉（1 秒）」加兩格。時間軸不顯示 state 的關鍵影格。

### 附著 attach

| 欄位 | 說明 |
|---|---|
| actor | 角色 id（必須是 actors 裡的） |
| joint | 關節名稱。可手持物品省略時用 rHand；左手 lHand 會自動鏡像握法。`"root"` 是整個人：物品跟著角色的位置與朝向移動（含轉彎傾斜），不跟著手或上身擺動（騎車用；pos 公尺、rot 角度，都是角色座標，不隨身高縮放） |
| from / to | 附著的時間 from ≤ t < to。省略 from 是從頭開始，省略 to 是到最後 |
| pos / rot | 選填，自訂握的位置（公尺，關節座標）與旋轉（角度）。寫了就不用內建握法 |
| upright | 選填，true 時物品保持直立，只跟著角色轉向、不隨手腕傾斜（雨傘預設 true） |
| blend | 選填，秒數。從 from 起花這麼久從原本的位置（物品路徑，或上一段那隻手）滑進手裡 |
| throw | 選填，秒數。to 之後沿拋物線飛這麼久，落在物品 path 在 to + throw 的位置 |
| arc | 選填，拋物線比直線高出的公尺數，預設 0.5（throw 有寫才有用） |

- 附著時間以外，物品回到自己的 path。所以「從桌上拿起」：path 放桌上、from 設拿起的時間、`blend` 0.3；「放下」：to 設放下的時間，path 在 to 之後要有一格放在放下的位置；「丟出去」：寫 `throw`（0.3 到 0.6）與 `arc`，path 在 to + throw 放一格落點。
- 拿起的瞬間搭配 `pickUp`（全身）或伸手的 upper 動作，畫面才合理。
- 內建握法的握點跟著角色身高移動，物品本身大小不變（兒童拿杯子不會縮小）；自訂的 pos 依身高等比縮放。
- 同一個物品要換手或放下後再拿起，attach 寫成陣列，每段一個物件，依 from 排序、時間不重疊：

```json
"attach": [
  { "actor": "mei", "joint": "rHand", "from": 1, "to": 4.2, "blend": 0.3 },
  { "actor": "jie", "joint": "rHand", "from": 4.2, "blend": 0.25, "upright": true }
]
```

前一段的 to 等於下一段的 from 時，下一段的 blend 會從前一個人的手滑過來（交接）；中間有空檔時，空檔裡物品回到 path。

### 雙人動作

`handshake`（握手）、`hug`（擁抱）、`give`（遞出）、`receive`（接過）兩個人都要放，片段的 `start`、`dur` 相同，`params.with` 填對方的 id。手會伸到兩人之間，所以兩人的距離要對：

| 動作 | 兩人站立點的距離（男女、男童、女童組合） |
|---|---|
| handshake、give、receive | 0.80 到 0.88 公尺 |
| hug | 0.22 到 0.30 公尺 |

用 `body` 改過身形時距離會變：胖的人擁抱要站遠一點（兩人 build 1.6 約 0.47 公尺），瘦的近一點。編輯器的自動擺位會照實際身形算。兩人身高差超過 1.8 倍（例如 2 公尺的大人和 1 公尺的小孩）時手對不上，檢查會出警告；這種畫面改用 `pose` 讓高的人蹲下。

兩人面對面（yaw 互相對著）、片段期間路徑不要動。給東西時物品的 attach 在片段中點換手：giver 那段 to 與 taker 那段 from 都寫 start + dur / 2，兩段都 `"upright": true`，taker 那段 `"blend": 0.25`。編輯器裡按住 Ctrl 選兩個人再按雙人動作，會自動算距離、轉向並換手。

### 日常動作配方

下表的位置都相對於物品（物品在 [0, 0, 0]、yaw 0），實際專案把同一個位移加上去。可參考 `ROOT/spikes/a03-daily.blockingpro.json`。

| 情境 | 寫法 |
|---|---|
| 推門 | 門 `door` 往 -Z 開。人站 [0.17, 0, 0.45]，`"facing": "fixed"`、yaw 180，upper 放 `openDoor`（2.5 秒）、`params.push` 1。右手伸到門把、轉、往前推。門板要跟著開：門的 state 在 start + 1 秒寫 0（`"e": "inOut"`）、start + 2 秒寫 1（見「物品動畫」） |
| 拉門 | 人站門的背面 [0.255, 0, -0.44]，yaw 0，`openDoor` 的 `push` 0。門往 -Z 開，會掃到站在背面的人：state 只開一點（0.3 左右），或讓人在門轉開前往後退 |
| 打字 | 辦公桌 `desk` 在原點，椅子 [0, 0, 0.56]、yaw 180，人 [0, 0, 0.16]、yaw 180：`actions` 放 `sitting`（`seat` 0.45），`upper` 放 `typing`（循環，`rate` 每秒敲鍵次數） |
| 搬起、搬走、放下箱子 | 箱子 `box` 放地上，人站在箱子後方 0.49 公尺面向它。`actions` 放 `liftBox`（2.4 秒）；搬著走時 upper 放 `carry`，`params.ready` 1（手一開始就在搬的位置），片段從 liftBox 結束前 0.1 秒蓋到 putDown 開始後 0.1 秒；到定點放 `putDown`（2.4 秒）。箱子 attach 的 `from` = liftBox 開始 + 1.0（0.42 × 長度）、`to` = putDown 開始 + 1.15（0.48 × 長度）。箱子 path 三格：0 秒原位、`from` 同一個位置（不然會提早滑動）、`to` 人前方 0.49 公尺的地上 |
| 抱小孩 | 嬰兒 `baby` 的 attach 只寫 actor（預設右手），upper 放 `holdChild`（`rock` 搖晃幅度 0 到 2）。嬰兒躺在右前臂，頭在手肘內側，左手扶著 |
| 騎機車、腳踏車 | 車子（`motorcycle` 或 `bike`）和人放在同一點、yaw 相同，人 `"facing": "fixed"`。人的 path 照騎車路線移動，`actions` 放 `ride`（循環，`params.vehicle` 填 motorcycle 或 bike）；車子 attach 寫 `{ "actor": "人", "joint": "root" }`，車就跟著人走。腳踏車踏板依騎過的距離轉（每 5 公尺一圈），曲柄跟著腳轉；兩種車的車輪都依距離滾動 |
| 邊走邊看手機、講電話 | 手機 `phone` attach 到角色，upper 放 `lookPhone`（手機在胸前、螢幕朝臉）或 `phone`（貼耳），path 照常移動 |
| 上下樓梯 | 不需要動作，路徑走過樓梯就會爬（見「可行走的物品」） |

- 箱子、嬰兒的握法照成年男性調整；兒童或體型差很多的角色手可能對不準，用 attach 的 `pos`、`rot` 修正。腳踏車座高固定，身高 1.55 公尺以下的人踏板轉到最低點時腳會離開踏板（1.4 公尺差約 9 公分，兒童 1.2 公尺差約 18 公分）；機車各種身高都踩得到踏板。
- 停車時 ride 仍是坐姿，沒有放腳撐地；角色之間不能互相抱起（抱小孩用的是嬰兒物品）。

## 6. 燈光 lights

```json
{ "id": "lamp", "type": "spot", "name": "路燈光", "color": "#ffd9a0", "intensity": 40, "angle": 35, "distance": 0, "shadow": true,
  "path": { "keys": [ { "t": 0, "v": [2, 4, 1] } ] }, "aim": [0, 0, 0] }
```

- `type`：`spot` 聚光燈（有 aim、angle）或 `point` 點光源。
- `intensity` 預設 40；`angle` 是聚光燈張角（度）；`distance` 0 表示不限距離。
- `aim`：固定點 [x, y, z]，或 `{ "actor": "mei" }` 跟著角色。
- 整體亮度先用 settings.lighting 預設（day、night、indoor 等），燈光物件只在需要重點光、路燈、手電筒時加。

## 7. 攝影機 cameras

```json
{ "id": "camA", "name": "A 機 全景", "color": "#ff9f1c",
  "path": { "keys": [ { "t": 0, "v": [0, 1.6, 6] }, { "t": 4, "v": [0, 1.6, 3.5], "e": "inOut" } ] },
  "aim": { "mode": "actor", "actor": "mei" },
  "lens": 35, "roll": 0, "shake": 0 }
```

| 欄位 | 預設 | 說明 |
|---|---|---|
| path | [0, 1.6, 6] | 攝影機位置。y 是鏡頭高度：平視 1.5 到 1.7，低角度 0.3 到 0.6，鳥瞰 8 以上 |
| aim | 看 (0, 1.2, 0) | 鏡頭看哪裡，見下 |
| mount | null | 掛在角色身上跟拍，見下。有 mount 時忽略 path |
| lens | 35 | 焦距（mm）。數字固定，或關鍵影格 `[{ "t": 0, "v": 24 }, { "t": 3, "v": 70 }]` 做變焦 |
| roll | 0 | 鏡頭側傾（度），可用關鍵影格 |
| shake | 0 | 手持晃動強度，0.4 到 0.8 像手持，超過 1.5 很晃 |
| shakeStyle | handheld | 晃動樣式：handheld 手持、walk 手持走路、breathe 呼吸微晃、vehicle 車上震動、impact 衝擊震動（持續震動，不是單次撞擊）。shake 為 0 時無效 |
| dof | null | 景深 `{ "fstop": 2, "focus": null }`：fstop 1 到 22（越小背景越糊），focus 對焦距離（公尺），null 自動對焦在 aim 的位置。只作用在導演台主畫面與輸出 MP4，check_scene 的截圖也會套用 |

### aim

- 看角色：`{ "mode": "actor", "actor": "mei" }`。不寫 offset 時看胸口和頭之間（動物看身體和頭之間），角色走到哪鏡頭跟到哪。
- 加 offset：`{ "mode": "actor", "actor": "mei", "offset": [0, 1.6, 0] }`，看「角色腳底位置 + offset」。offset 是世界座標，不隨角色轉向。看臉：offset y 約身高的 0.92（男 1.62、女 1.52）；看腳：y 0.1。
- 看固定點或移動的點：`{ "mode": "point", "curve": "smooth", "keys": [ { "t": 0, "v": [0, 1.2, 0] } ] }`。keys 寫法和 path 一樣，多格就是搖鏡。
- aim 的 actor 只能是角色。要看物品，用 mode point 寫物品的位置。

### mount（跟拍）

```json
"mount": { "actor": "mei", "offset": [0, 1.7, -3.2], "rotate": true }
```

- 攝影機位置 = 角色腳底 + offset。`rotate: true` 時 offset 跟著角色轉向（offset 用角色自己的方向：+Z 是角色前方，-Z 是背後，+X 是角色的左邊）。
- 背後跟拍 [0, 1.7, -3.2]；側面跟拍 [3.5, 1.4, 0]（角色左側）；正面倒退拍 [0, 1.5, 3]。
- mount 通常搭配 aim 看同一個角色。

## 8. 剪接 cuts

```json
"cuts": [
  { "t": 0, "camera": "camA", "note": "全景：小美從左邊走進公園" },
  { "t": 3.2, "camera": "camB", "note": "中景：小美停下揮手" }
]
```

- 每個剪接點從 t 開始切到這台攝影機，直到下一個剪接點。第一個剪接點之前用第一個剪接點的攝影機，所以第一個 t 寫 0。
- `note`：這一鏡的說明，最多 300 字，會顯示在時間軸、導演台、檢查用的分鏡表上。寫景別、動作、情緒，Seedance 提示詞可以從這裡延伸。
- 一個鏡頭（兩個剪接點之間）建議 1.5 到 5 秒。
- 同一台攝影機可以用很多次。攝影機的 path / lens 關鍵影格要涵蓋它被剪進來的時間；鏡頭沒被選用的時間怎麼動都不會出現在成片裡。
- 推軌、搖鏡這類運鏡，關鍵影格的時間要落在該鏡頭的剪接區間內，不然觀眾看不到運動。
- 編輯器鏡頭表的「標示景別」在每鏡中間那一格量景別：攝影機 aim 對準角色且那個角色在畫面裡時量他，否則量畫面裡最大的角色；畫面下緣切在哪個關節決定景別，所以坐著、蹲著也量得出來（腳踝以下被切掉仍算全景）。量完在 note 前面加【全景】【中景】這類標籤（已有標籤就換成新量到的，不會疊兩個）；SKILL 寫 note 時也可以自己先寫【景別】，格式相同。景別名稱：大遠景、全景、中遠景、中景、中近景、特寫、大特寫、空景。
- 編輯器鏡頭表的「越軸檢查」會比對剪接前後兩個角色的左右順序，對調時列出是哪一個剪接點。只檢查左右順序，不檢查移動方向和視線方向。刻意的反拍（例如從物品後方拍）也會被列出，確定是故意的就在分鏡表說明。

### 對白字幕 subtitles

```json
"subtitles": [
  { "t": 4.6, "dur": 2.0, "text": "這雨也下太大了吧。", "actor": "jie" }
]
```

- 放在最上層（和 cuts 同層）。`t` 開始秒數，`dur` 顯示秒數（最少 0.2，沒寫是 2），`text` 最多 200 字，`actor` 選填，填說話角色的 id。
- 字幕顯示在導演台下方；輸出 MP4 時可以勾「燒入對白字幕」（交給 AI 影片模型當參考時建議不勾）。在編輯器時間軸的「對白」軌雙擊可以加一句。
- 角色嘴巴不會動，要看得出誰在說話，在同一時間給說話的角色放 `talk`（upper 軌）。
- 檢查訊息：`actor` 不存在、字幕超出總長時列為警告。
- 時間標記 `settings.markers`（`[{ "t": 2, "label": "轉身" }]`，label 最多 40 字）只在編輯器時間軸的尺規上顯示，不會出現在輸出，用來標節拍，見 catalog.md 的「場景設定」。`tools/script_import.py` 產生的骨架把每行動作描述寫成一個時間標記。

內建物品以外的道具放在 `assets`，props 的 type 填它的 id。格式見 assets.md。存檔時編輯器只保留有被 props 用到的自訂物品。

## 10. 檢查訊息

- 錯誤（errors）：格式錯、未知代號、id 重複、引用不存在的角色或攝影機。有錯誤時畫面可能不對，一定要修。
- 警告（warnings）：超出總長、超過目標模型（settings.target）的長度、解析度或 fps 範圍、沒有攝影機、角色直接跨上或掉下可行走物品的邊緣。看情況處理。
- `python tools/check_scene.py 專案.json --shots` 會列出所有訊息，並輸出每一鏡的截圖 sheet.png 和俯視圖 overview。
- check_scene 另外列出（不影響 exit code）：
  - 景別：每一鏡的景別，算法同「標示景別」，括號是被量的角色。和分鏡表對照。
  - 穿模：每 0.1 秒取樣，人是地上的圓（半徑約身高 × 0.12），物品是 1.8 公尺以下零件的底面方框（路燈燈臂、樹冠不算，可以從下面走過），重疊超過 0.1 公尺就列出時段，例如「1.5 到 2.5 秒：小美穿過桌子」。坐下、躺下（sit、sitting、lie、standUp 和坐下前 1.2 秒原地轉身）不算和家具重疊；手上拿的、可行走的物品不算。最多列 20 處。
  - 越軸：同「越軸檢查」。
